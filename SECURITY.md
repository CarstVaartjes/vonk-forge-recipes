# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub. Open the
repository's **Security** tab and choose **Report a vulnerability**
(<https://github.com/CarstVaartjes/vonk-forge-recipes/security/advisories/new>). Do not put
the details in a public issue, pull request or discussion.

If the form is not available, open a public issue titled "Security contact
request" with no details. The maintainer then opens a private advisory with
you.

## Supported versions

Only `main` and the newest catalog release are supported. Recipes are refreshed
in place, so a fix ships as a new revision of the same recipe; older catalog
releases are not patched.

## Scope

The recipe definitions, adapters, recipe tooling and the published recipe
images. A bug in an upstream engine or in a creator's own repository belongs
with that upstream. Please tell us too when a Vonk Forge recipe ships it, so we
can update or pull the recipe.
